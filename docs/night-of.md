## If something breaks

Keep the same room. Do not start a spare lobby unless the original cannot be
opened at all. Full steps: [event runbook](event-runbook.md).

| If…                                   | Do this                                                                                                                                                                                                                                                                               |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Phone lost or battery dead            | Live controls → that player → **Recover**. Read the one-time code to them (never on the projector). On the new phone: room join link → **Changed phones?** → enter the code. Old cookie stops. Retry the same code before asking for another.                                         |
| Guest changing phones (still in)      | **Phones → Transfer**. Same redeem flow. A new code replaces unused older ones.                                                                                                                                                                                                       |
| Phone only lost Wi-Fi                 | Reload the same tab. The guest cookie is the seat; stored answers stay. Guests see nothing for 1.5 s, then Reconnecting, a hint at 10 s, Try again now at 30 s.                                                                                                                       |
| Projector disconnect                  | Room health: Stage 0 means the projector browser is offline. `P` to pause if a question is collecting (the room does not pause by itself). Fix the laptop network; it reconnects without a reload. Then `P` to resume. Reload `/host` only if it stays on “Reconnecting to the room.” |
| Venue Wi-Fi drop                      | Same room. Phones and stage retry with jitter. Humza reloads `/admin` and signs in again only if the control cookie expired (12 h).                                                                                                                                                   |
| Need a beat to settle late arrivals   | Pause (`P`). Late arrivals start at zero. They can still answer an ordinary open question; frozen votes, duels and kart grids stay frozen.                                                                                                                                            |
| Typed or vote line should not be seen | Live controls → Responses → **Hide {nickname}'s answer**. It leaves phones and the stage; scores do not change. Restore brings it back. Votes already cast for a hidden ballot line stop counting until restore.                                                                      |
| Hide the whole projector              | `H` (Hide stage content). `R` shows the reveal again on reveal/scores/final/podium.                                                                                                                                                                                                   |
| Kart stuck off the road               | Guest presses **Back to track** on the phone (two-second cooldown; paused races cannot recover). Host: Pause/Resume for the whole race clock; **Stop item spawning** / **Clear track items** if items are the problem.                                                                |
| Need another kart race                | Kart-only lobby: after the podium, **Race again** (same join code), then **Start kart race**. Birthday order: this is the last round; do not invent a second Grand Prix unless you already created a separate kart lobby.                                                             |
| One phone tapping too fast            | The room tells them to wait a moment. Nothing for Humza.                                                                                                                                                                                                                              |
| Control tab died                      | Reopen production `/admin`, sign in, leave the tab open. It holds the control connection.                                                                                                                                                                                             |

## End of night

1. Reach the podium, or finish if the room must stop. Fun facts may sit between
   final and podium; Advance through them.
2. Refresh room health. Note archive status and any failed media or email
   counts.
3. If the archive export failed: **Retry archive export**. That retries; it
   does not wipe Neon.
4. Download the score summary (markdown of nicknames and points). That is the
   operator copy, not the public page.
5. Open `/r/{gameId}` once the archive has a publication. Until then the page
   says the archive is not built yet.
6. Retry email jobs if Room health shows pending or failed mail. Production
   sends to the guest address they gave. Staging only mails the configured test
   recipient.
7. Leave the admin tab until those checks are done, then sign out. Close the
   projector browser.
