# Where are we?

Map-guess round: guests study a clue photo, drop one pin, and send it. Scoring
is the shared map-guess curve (100 at the spot, half at about 693 km). Forty
seconds to answer.

The clue is a Wikimedia Commons photograph of a brick seafront promenade
(Elmschrat, CC BY-SA 3.0). The filename is `photo.webp`; the credit and alt
text do not name the place. The target and reveal copy stay on the server until
the reveal beat.

Admin → Question packs → Where are we? → Phone preview uses the live guest
layout and the real public photo. The design bench at `/design?q=where-are-we`
still uses a labelled stand-in harbour, never the answer key.

The custom presentation `where-are-we` is phone + projector chrome only. It
does not change scoring, timers, or snapshots.
